# Security policy

This repository is the source of a static personal portfolio. It has no server, login or database.

## Reporting a problem

If you find a security issue, such as exposed personal data, a broken security header or a dependency problem, please report it privately with GitHub's **"Report a vulnerability"** button on this repository's Security tab. Please don't open a public issue.

You can expect an acknowledgement within 7 days. This is a personal project, so there's no bug bounty.

## Supported versions

Only the current `main` branch and the live site built from it are maintained.

See [docs/security.md](docs/security.md) for the threat model and implemented controls.
