## What I built

An offline Android app that calculates pay from entered shifts and exports results as CSV or PDF.

## How it is built

- **App:** HTML, CSS and JavaScript packaged for Android with Apache Cordova.
- **Builds:** Docker and GitHub Actions automate Android builds and signed releases.
- **Troubleshooting:** I diagnosed and fixed JDK compatibility problems and missing Android build-tool issues in the build pipeline.

## Testing and quality

- Wrote 24 unit tests.
- Input validation guards against invalid or incomplete shift entries.
- Tested on a physical Android device as well as in the build pipeline.
- Parts of the code were written with AI assistance. I reviewed and debugged that code myself before keeping it.

## Status

Version 1.0.0 is published on GitHub Releases, and development is continuing.
