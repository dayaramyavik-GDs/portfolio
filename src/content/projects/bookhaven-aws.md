## Context

A university group project for my Master of Information Technology at Central Queensland University. The design work was shared across the group.

## The architecture

- An **application load balancer** in front of the application tier.
- **Private EC2 application servers** behind the load balancer.
- **VPC networking** for the environment.

## My contribution

- Contributed to the hosting architecture design.
- Prepared the technical documentation and presentation material explaining the architecture.

## What it demonstrates

Network segmentation with private application servers behind a load balancer, and documenting a cloud design so others can follow it.
